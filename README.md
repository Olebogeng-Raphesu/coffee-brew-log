## Quick Start

```bash
# 1. Start the backend
cd backend && ./mvnw spring-boot:run -Dspring-boot.run.profiles=dev

# 2. Start the frontend (new terminal)
cd frontend && npm install && npm start
```

Visit [http://localhost:3000](http://localhost:3000)
